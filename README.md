# Protocol Trace

My personal blog built with [Astro](https://astro.build).

## Development

### Requirements
- [nvm](https://github.com/nvm-sh/nvm) (Node Version Manager)

### Setup
```bash
# Install the correct Node.js version
nvm install

# Install dependencies
npm install

# Start the development server
npm run dev
```
